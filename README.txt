NEON RPG — Multi-page visual prototype

Open index.html in a modern browser, or serve this folder with any static web server.
All UI labels are in English. The generated image montage was cropped into six visual assets in /assets.

Working prototype features:
- Six navigable pages: Home, Chat, Characters, World, Store, Settings
- Responsive mobile layout with neon purple visual design
- Character selection and locally saved custom heroine names/personality tags
- Local chat messages with demo replies (not an AI connection)
- World selection feedback
- Demo coin purchases and theme accent color
- Export of basic save data

Notes:
- Character cards currently reuse cropped artwork from the generated concept image; separate full-resolution portraits can be added later.
- No backend, real AI API, real purchases, voice calls, or cloud sync are connected.
