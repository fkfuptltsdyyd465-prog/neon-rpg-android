# NEON RPG — AI Character Chat

نسخه ارتقایافته پروژه با چت هوش مصنوعی واقعی، حافظه محلی جداگانه برای هر شخصیت، و پروفایل کامل کاراکتر.

## اجرا

1. Node.js نسخه 20 یا جدیدتر نصب باشد.
2. در پوشه پروژه ترمینال باز کن و اجرا کن:

   ```bash
   npm install
   ```

3. فایل `.env.example` را به `.env` تغییر نام بده و کلید API خودت را در آن قرار بده:

   ```env
   OPENAI_API_KEY=کلید_شخصی_تو
   OPENAI_MODEL=gpt-5.5
   PORT=3000
   ```

4. اجرا:

   ```bash
   npm start
   ```

5. در مرورگر باز کن: `http://localhost:3000`

## نکته‌های مهم

- کلید API فقط روی سرور خوانده می‌شود؛ آن را داخل `index.html` قرار نده و با کسی به اشتراک نگذار.
- برای استفاده از API به حساب و اعتبار API جداگانه نیاز است؛ اشتراک ChatGPT به‌تنهایی اعتبار API محسوب نمی‌شود.
- گفت‌وگوها و شخصیت‌ها در localStorage مرورگر ذخیره می‌شوند. پاک کردن داده‌های سایت یا عوض کردن مرورگر ممکن است آن‌ها را حذف کند.
- حافظه‌ی گفتگو از طریق ارسال تاریخچه‌ی اخیر (تا ۳۰ پیام) به مدل حفظ می‌شود؛ این حافظه‌ی دائمیِ خلاصه‌شده یا همگام‌سازی ابری نیست.
- برای انتشار عمومی، احراز هویت، محدودیت درخواست، سیاست حریم خصوصی و پایگاه داده اضافه کن.
